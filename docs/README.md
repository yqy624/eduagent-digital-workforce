# 文档索引

根目录只留 `README.md`（门面）和 `LICENSE`，其余全部下沉到这里。

## 三、文档写作约定

- 结论先行：第一段就说清「是什么 / 为什么」，背景与推演放后面。
- 只写可验证的事实：涉及行为的描述要能指到代码或实测结果，方案推演要标明是推演。
- 面向用户写作：不写内部字段名、接口路径、模块代号（技术文档除外，需给出路径供检索）。
- 一次性执行报告进 `09-历史归档`，不再回改；长期有效的规则进对应分类目录。
